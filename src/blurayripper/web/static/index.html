TV box sets

One row per disc (or per set, with a *). A disc whose label matches is named and ripped automatically — no mapping form.
Disc label and Show are required. Leave Season / First ep blank to read them off the label (HAWAII_FIVE_0_S1_D4 → season 1, disc 4). Episodes is an optional safety check — if the disc has a different number of episode-length titles, it stops and asks instead of guessing. A trailing * in the label covers a whole set.
